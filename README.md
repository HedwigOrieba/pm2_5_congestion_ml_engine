# pm2_5_congestion_ml_engine
A repo for a machine learning model that relates selected traffic congestion measuremen indicators to PM_2.5 pollution levels in kampala.
The model focuses on the contibutive level of traffic congestion indicators like mean spead, mean duration and traffic performance index to pm2.5 pollution level forecasting.
It integrates traffic congestion data obtained from the google routes api to pm2.5 pollution measurements from Makerere university AirQo sensor network initiative.
It adopts a methodological pipeline of data ingestion, standardisation, synchronization, augmentation and merging. The final dataset is then subjected to a machine learning process for finalized results attainment.
