# pm2_5_congestion_ml_engine
A repo for a machine-learning model that relates selected traffic congestion measurement indicators to PM_2.5 pollution levels in Kampala, Uganda.
The model focuses on the contibutive level of traffic congestion indicators like mean spead, mean duration and traffic performance index (TPI) to pm2.5 pollution level forecasting. It integrates traffic congestion data obtained from the google routes api to pm2.5 pollution measurements from Makerere university AirQo network of PM2_5 pollution sensors. It adopts a methodological pipeline of data ingestion, standardisation, synchronization, augmentation and merging. The final dataset is then subjected to a machine-learning process for traffic-indicator evaluation assessment.
